# YNS Affiliate Store (Minimal React + Vite)
## What is this
A minimal starting template for an affiliate storefront built with React + Vite.

## How to run
1. Install Node.js (v18+ recommended).
2. In project folder run:
   ```
   npm install
   npm run dev
   ```
3. Open the local dev URL shown by Vite.

## Customize
- Replace `sampleProducts` in `src/App.jsx` with real product data.
- Replace affiliate links with your tracking URLs.
- Add images to `public/` and update paths.
- Consider adding routing, CMS, or server-side rendering for scalability.
